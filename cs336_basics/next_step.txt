merging efficiently:
- create dictionary from the list of merges: k: pair, value: rank
- split input string using the regex to word list
- for every word list, split into the individual bytes
- for every word byte list
 - build a deque 
 - build a min heap using key (rank, deque_idx)
  - include only the one that is exist in dict of merges (rank should exists in the dict of merges)
 - while merge process:
  - pop key
  - get the deque index from key
  - update the left element and the right element
  - if left element exist in dict of merges, push to heap
  - if right element exist in dict of merges, push to heap
